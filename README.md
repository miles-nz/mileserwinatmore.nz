# mileserwinatmore.nz

Personal portfolio site.

## Getting started

```bash
npm install
npm run dev       # Start dev server (Vite)
```

Other scripts (used by Github Actions):

```bash
npm run build     # Production build to dist/
npm run lint      # ESLint
npm run deploy    # Build and deploy to GitHub Pages (gh-pages -d dist)
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for how the site is put together.

## Stack

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Motion](https://motion.dev/) for animation
- [react-icons](https://react-icons.github.io/react-icons/)
- Deployed via [gh-pages](https://www.npmjs.com/package/gh-pages)
